# ShadowsocksX-NG-R8 v2.0.1

- 服务器测试改为通过每个节点发起真实 HTTPS 代理请求，TLS 验证成功且返回 HTTP 204 才显示耗时；失败后重试一次。
- 耗时后显示“直连 / 中继 / 路径未知”，支持 Tailscale 和 ZeroTier；悬停查看测试时间、路径来源及失败原因。
- 修复测试失败后残留旧结果、排序刷新覆盖正在编辑的配置等问题。
- 检查更新与下载地址改为本仓库。

## 安装与使用

下载 `ShadowsocksX-NG-R8-v2.0.1-arm64.dmg`，退出旧客户端后，将应用拖入“应用程序”并打开。发行包适用于 **Apple Silicon（arm64）、macOS 14 或更新版本**。

应用使用 ad-hoc 签名，未经 Apple 公证。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许打开。

菜单中的“服务器代理请求测试”显示的是 HTTPS 请求总耗时，包含连接和 TLS 协商，**不是 ICMP 延迟或下载带宽**。路径为测试时快照；无法确认时显示“路径未知”。

macOS 27 可能隐藏 ZeroTier 所需的邻居信息。可在“服务器设置 → ZeroTier 节点…”填写目标服务器的 10 位节点 ID 后重新测试。详见[使用说明](https://github.com/sadlll/SS-NG-R8/blob/v2.0.1/docs/proxy-diagnostics.md)。

# ShadowsocksX-NG-R8 v2.2.0

- 节点列表的主数值改为真正的 ICMP Ping RTT，采集三次回复的平均值，支持 IPv4 和 IPv6。
- 代理可用性继续通过真实 HTTPS 请求独立验证，显示为 `92.4 ms · TCP RELAY · 可用`。完整 HTTPS 请求耗时移至悬停说明。
- 节点不回应 Ping 时显示“PING 不可用”；代理请求仍可独立判为可用，避免把禁 Ping 当成代理失败。
- 延迟排序和最快节点标记改用 Ping RTT，最快节点同时要求代理请求成功。
- 保留具体错误提示、TLS 验证、取消测试和应用内签名更新。服务器配置及当前节点保持不变。

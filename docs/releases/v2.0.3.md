# ShadowsocksX-NG-R8 v2.0.3

- 连接状态改用类似 UU 远程的简短标识：`UDP LAN`、`UDP P2P`、`TCP RELAY`、`UDP RELAY`、`RELAY` 和 `UNKNOWN`。
- 自动区分已确认的物理局域网直连与一般节点直连；LAN 识别检查物理路由，避免将虚拟内网地址误认作局域网。
- 悬停保留中文解释、Tailscale/ZeroTier 路径来源和测试时间。

`UDP`/`TCP` 描述本机到代理节点的承载链路，HTTPS 代理请求测试继续验证真实代理可用性。中继协议无法确认时仅显示 `RELAY`。

## 安装

下载 `ShadowsocksX-NG-R8-v2.0.3-arm64.dmg`，退出旧版后替换应用，再运行“服务器代理请求测试”。适用于 Apple Silicon、macOS 14 或更新版本。

应用使用 ad-hoc 签名，未经 Apple 公证。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许打开。

详见[标识说明](https://github.com/sadlll/SS-NG-R8/blob/v2.0.3/docs/proxy-diagnostics.md)。

## 验证

23 项自动化测试、中文菜单模型检查和 Release 编译通过；已用实际 Tailscale 局域网直连节点及 DERP 中继节点核对标识。

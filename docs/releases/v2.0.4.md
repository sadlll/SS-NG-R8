# ShadowsocksX-NG-R8 v2.0.4

- 修复 ZeroTier 节点路径查询始终显示 `UNKNOWN` 的子进程环境问题。
- 未指定专用环境时继承当前用户环境，使 ZeroTier CLI 能读取本地认证文件；Tailscale 继续显式使用 CLI 模式。
- 新增环境继承及显式覆盖的回归测试。

此修复恢复路径查询，不会消除 ZeroTier 网络本身的丢包或中继抖动。`请求失败` 表示真实代理请求未完成，与路径是否识别是不同结果。

macOS 隐藏邻居信息时，仍需在“服务器设置 → ZeroTier 节点…”填写目标服务器的 10 位节点 ID，才能准确关联路径。

## 安装

下载 `ShadowsocksX-NG-R8-v2.0.4-arm64.dmg`，退出旧版后替换应用，再运行“服务器代理请求测试”。适用于 Apple Silicon、macOS 14 或更新版本。

应用使用 ad-hoc 签名，未经 Apple 公证。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许打开。

## 验证

24 项自动化测试、中文菜单模型检查和 Release 编译通过。已在不含终端环境变量的精简环境中，验证实际 ZeroTier CLI 的认证读取、网络与节点查询，以及关联节点后的 `RELAY` 标识。

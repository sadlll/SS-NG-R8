# ShadowsocksX-NG-R8 v2.1.0

- 新增应用内更新：在“帮助 → 检查并安装更新…”发现新版后，可直接下载安装并重启，无需手动解压替换。
- 自动校验更新包和更新说明的 Ed25519 签名，并在解压前验证更新包。
- 更新只替换应用程序包，保留服务器配置、当前节点和代理设置。
- 更新检查以 GitHub 已正式发布的版本为准，保留原有的启动时检查更新选项。

2.0.x 首次升级到本版仍需安装新应用；之后可以在软件内更新。适用于 Apple Silicon、macOS 14 或更新版本。

应用本体仍使用 ad-hoc 签名，未经 Apple 公证；自动更新使用独立的 Ed25519 签名校验。

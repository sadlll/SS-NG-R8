# ShadowsocksX-NG-R8 v2.0.2

- 修复从 Finder、Dock 或登录启动时，Tailscale 节点全部显示“路径未知”的问题。
- 查询 Tailscale 状态时明确使用 CLI 模式，不再依赖终端环境变量。
- 新增无终端环境的回归测试，覆盖 Tailscale 返回 GUI 错误文字但退出码仍为 0 的情况。

## 安装与使用

下载 `ShadowsocksX-NG-R8-v2.0.2-arm64.dmg`，退出旧客户端后，将应用拖入“应用程序”并打开，再运行“服务器代理请求测试”。

发行包适用于 **Apple Silicon（arm64）、macOS 14 或更新版本**。应用使用 ad-hoc 签名，未经 Apple 公证；若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许打开。

ZeroTier 仍需足够证据才能识别路径。macOS 27 隐藏邻居信息时，请在“服务器设置 → ZeroTier 节点…”填写目标服务器的 10 位节点 ID。请求失败并不等于走中继。

详见[代理测试与路径识别说明](https://github.com/sadlll/SS-NG-R8/blob/v2.0.2/docs/proxy-diagnostics.md)。

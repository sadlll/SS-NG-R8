# ShadowsocksX-NG-R8 v2.1.2

- 修正代理测速的超时预算：SOCKS/TLS 握手从 5 秒增加至 15 秒，单次 HTTPS 请求最多 25 秒，兼容部分存在重传的中继链路。
- 同步临时代理的连接超时与请求预算，避免辅助进程先于 HTTPS 请求结束。
- 区分临时代理启动失败、请求超时与一般请求失败，避免全部显示同一条错误。
- 菜单悬停可查看具体 curl 错误；增加不包含密码或代理配置的测试结果日志。
- 新增本地 SOCKS + TLS 回归测试，验证握手需 6 秒但可正常返回 HTTP 204 的代理不会再被过早判失败。

此更新改进测速与错误显示，不会改变 Tailscale/ZeroTier 的直连或中继路径。服务器配置、当前节点及应用内更新功能保持不变。
